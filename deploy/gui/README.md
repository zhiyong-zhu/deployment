# CICT 部署向导（Web UI）

单文件、仅依赖 Python 3 标准库的本地部署向导。**职责边界**：UI 只负责配置编辑、触发执行与结果展示；全部部署动作由 `deploy/bundle/install.sh` 完成，本程序不复制部署逻辑，install.sh 的幂等/密码/校验行为对 UI 完全一致。

## 启动

```bash
# 在线模式：目标机仓库内（Ubuntu 24.04 自带 python3，无需安装任何依赖）
sudo python3 deploy/gui/deploy-gui.py

# 离线模式：bundle 解压目录内（build-bundle.sh 会自动把本文件打进安装包）
sudo python3 deploy-gui.py
```

浏览器访问 `http://127.0.0.1:8788`。远程操作先建 SSH 隧道：

```bash
ssh -L 8788:127.0.0.1:8788 <用户>@<服务器IP>
```

## 界面流程

1. **① 配置**：部署目录、端口、版本号（在线模式含 JAR/前端路径）；密码组每项可单独"随机"或留空由安装时自动生成；检测密码含 `$` 时提示（Compose 需 `$$` 转义）；"高级配置"可直接编辑 compose/nginx/MariaDB/Spring Boot 配置原文
2. **② 一键安装**：触发 `install.sh`（在线/离线模式自动识别），实时滚动安装日志，显示退出码。国内网络可在此页指定 Docker apt 源基地址与镜像加速器；两者留空时安装前自动探测连通性——apt 源按 官方 → 阿里云 → 中科大 → 清华，镜像源先测 Docker Hub 直连、不通再按 1ms → DaoCloud → 1Panel 选第一个可用加速器
3. **③ 验证**：逐项检查六个容器运行与健康状态、前端 200、后端 API 探活、管理端口监听，并提示创建 `pike` 存储桶

保存配置会写入 `<部署目录>/.env`（权限 600）；已存在的 `.env` 值会回显到表单，重复保存/重装不会丢失密码与数据（与 install.sh 幂等语义一致）。

## 安全边界

- 只绑定 `127.0.0.1:8788`，不对外监听；以 sudo 运行是为了让 install.sh 能安装 Docker 与写 `/data`
- UI 无认证，仅限单一操作者经 SSH 隧道使用，不要把端口转发给不可信网络
- 密码只写入 `.env`（600），不进入安装报告与日志
